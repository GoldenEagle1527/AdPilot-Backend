# ADR 0019：对接由后端做主；OpenAPI + 对接短文；前端无自有业务逻辑

状态：accepted  
废止：[0018](0018-前后端两个Git仓库.md) 里的「第三计划仓」和「契约只改 Plan」；废止 [0016](0016-未决收口.md) 对 Q-BE-2「先 markdown、后 OpenAPI」的口径。两应用仓仍有效。

## 决定

1. **`Plan/` 只是当前把计划写清楚**，不是第三个 Git 远程，也不当跨人通信面。实现期跟后端走；不加 `AdPilot-Plan`。
2. **只有两个应用仓**：后端 `AdPilot`、前端 `AdPilot-Frontend`。通信由**后端做主**。
3. **需求**：线下或群里说，不要求先合一份计划仓 PR。
4. **字段与路径的真源**：后端 **OpenAPI**（FastAPI `/openapi.json` / `/docs`）。前端自己拉，不要在前端仓抄字段表。
5. **接口一变（含新增）**：后端必须再输出一段**对接文本**（发群即可）：简要说改了啥或新加了啥。不要在这段里贴完整 schema。
6. **前端禁止自有业务逻辑**。展示、路由、拆信封可以；权限计算、数据拼装、过滤规则、默认值策略等一律打后端。所有业务请求必须打后端。

对接文本格式：[backend/接口变更对接.md](../backend/接口变更对接.md)。
