# ADR 0011：契约维护最新表与变更历史

状态：accepted

## 背景

接口会改。只靠 git log，Agent 和前后端对不上「现在到底是哪张字段表」。也不能为每次改动再抄一份参数手册。

## 决定

- 每份 `contracts/<endpoint>.md` 的请求/响应/错误表就是该接口的**最新表**。
- 同一文件底部维护「变更历史」。每次改语义或字段：文档版本 +1，历史最上行追加。
- 每个业务一块 `contracts/最新表.md`：一行一个当前接口（版本、方法、路径、干什么）。不在这里复制字段。
- 破坏性变更（删字段、改语义、改路径）：先把改之前的全文快照到 `contracts/_history/<endpoint>-v<旧文档版本>.md`，再改正文。兼容变更不做快照。
- 路径 `/api/v1` 只在破坏性变更时升到 `v2`。文档版本每次都升，不必等于 URL 版本。
- 禁止再做「最新参数.xlsx」或页面里第二份字段表。

细则：[architecture/契约版本.md](../architecture/契约版本.md)。

## 后果

改接口的 PR 必须同时改：当前契约、变更历史、`最新表.md`；破坏性还要有 `_history/` 快照。实现与最新表不一致 = 未完成。
