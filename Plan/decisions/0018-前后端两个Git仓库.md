# ADR 0018：前后端两个应用仓库，通信不靠同仓 PR

状态：accepted（仓数仍有效；**怎么对接已被 [0019](0019-后端OpenAPI对接.md) 覆盖**）  
修订：[0002](0002-Git与Gitea.md)、[0016](0016-未决收口.md) 里「一个 AdPilot 仓」的说法。产品名仍是 AdPilot。

## 决定

前后端**代码**是 **两个 Git 仓库**，不是一个仓里的 `backend/` + `frontend/`。

| 仓 | 预定名 | 装什么 |
| --- | --- | --- |
| 后端 | AdPilot | FastAPI、该仓 `deployment/` 与 Dockerfile |
| 前端 | AdPilot-Frontend | React、该仓 `deployment/` 与 Dockerfile |

**不要**第三个计划远程。`Plan/` 只是现在写计划。对接见 0019：OpenAPI + 群里对接文本。

禁止：子模块互引应用仓。
