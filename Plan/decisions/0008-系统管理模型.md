# ADR 0008：从管理中台截图锁定 system-admin 的数据模型与权限模型

状态：accepted

## 决定

- 第一块业务是 `system-admin`（产品「系统管理」）。
- 数据模型与权限模型以 `管理中台截图` 为准，写入 `Plan/modules/system-admin/`。
- 功能权限 = 角色 ↔ 菜单树（目录 / 菜单 / 组件），**无权限码**。
- 数据权限 = 用户 ↔ 自定义部门集合，与所属部门独立。
- 用户角色与部门角色是两套绑定。
- 负责人/成员是用户字段 `role_kind`，不是 Role。
- 「权限角色」不是实体，是反查。
- 本轮不写接口契约、不搭建应用、不复刻 UI。
- 投放 / 素材 / 报表不因出现在参考权限树里就开业务块。
- **后续收口**：具体节点清单不锁定，见 [0010](0010-锁定机制不锁定清单.md)。

## 后果

Q-MOD-1 对本块关闭。Q-PERM-1 对本块关闭。R4 改为：不得另造与本模型平行的全站权限码体系。
