# ADR 0009：用 system-admin 实例化模块化约定

状态：accepted

## 决定

- 通用切块（一业务一包、包内再拆接口/页面、shared 极瘦、契约先行）以 `system-admin` 为第一个实例，见 `architecture/融合.md`。
- 部门 / 用户 / 角色同属这一块，不拆成三个业务包；并行靠包内文件。
- 授权机器住在 `system-admin`。其它业务不自建权限台；通过公开能力（有效菜单、可见部门、`require_menu`）接入。
- shared 只带登录态和布局槽位；菜单内容不是 shared 的真源。
- 本轮仍不搭建代码、不写契约字段、不复刻 UI。

## 后果

模板的「权限」段改为指向本块，不再暗示每块业务再做一套后台。R1 允许其它包 import 本块公开窄口，仍禁止 import 内部模型。
