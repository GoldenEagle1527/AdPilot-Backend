# ADR 0013：遵守公司研发规范

状态：accepted

## 决定

Drooling 及后续重大重构遵守 [`../meta/公司研发规范.md`](../meta/公司研发规范.md) 五条：

1. 生产环境禁止宝塔及未经授权的第三方管理面板。
2. Redis 只准 7.2.x。
3. 关系库只准 PostgreSQL 18.x。
4. 依赖只准 MIT / Apache-2.0 / BSD-2/3 / ISC；GPL、AGPL、LGPL、EPL 须书面审批。
5. 素材须可商用开源或公司授权。

## 后果

后端定版见 [0014](0014-后端定版.md)。搭框架清单必须含许可证表。违规依赖不得合并。
