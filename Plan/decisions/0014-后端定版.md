# ADR 0014：后端定版

状态：accepted

关闭 Q-BE-1。公司规范见 [0013](0013-公司研发规范.md)。

## 决定

| 项 | 选择 | 许可证 |
| --- | --- | --- |
| 语言 | Python 3.12.x | PSF |
| Web | FastAPI + Uvicorn | MIT / BSD-3 |
| 校验 | Pydantic v2 | MIT |
| ORM | SQLAlchemy 2.x（asyncio） | MIT |
| 迁移 | Alembic | MIT |
| PG 驱动 | **asyncpg** | Apache-2.0 |
| 数据库 | PostgreSQL **18.x** | — |
| 缓存 | Redis **7.2.x** + `redis`（asyncio） | MIT |
| 信封 / 分页 | [`architecture/信封与分页.md`](../architecture/信封与分页.md) | — |

禁止：`psycopg` / `psycopg2`（LGPL）；生产用宝塔装库；把业务模型放进 `core`。

引擎、会话工厂、Redis 客户端在 `app/core/`。表模型住在各业务包（`system_admin` 等）。`core` 不出现 User/Role/菜单。

## 框架 vs 业务

后端框架已落地（真源 `backend/app/`）。健康检查、信封、yaml、Compose 以代码为准。  
system-admin 契约已写且已实现。未开块的投放等业务不要先写 CRUD。

## 后果

Q-BE-1 = resolved。登录：Header Token + 查库，Token 存 Redis。
