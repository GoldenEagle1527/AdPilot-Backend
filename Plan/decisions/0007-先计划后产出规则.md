# ADR 0007：现在只做计划；Cursor rules/skills 为日后产出

状态：accepted

## 决定

- 当前阶段只设计计划，不执行实现，不创建 `.cursor/rules`，不写 skill 文件。
- 规范的源在 `Plan/`。所谓「产出 rule」是：计划里写清日后要生成的禁令要点（R1–R5）与 skill 步骤要点（S1–S3）。
- 实现期生成的 rule 必须短、并链回 Plan，禁止把架构长文复制进 rule。

## 后果

`outputs/` 是清单，不是 Cursor 配置。阶段 3 才落地 rule 文件。  
搭前后端框架按 `backend/搭框架/`、`frontend/搭框架/` 执行（ADR 0013/0014），不改变「规范源在 Plan」这条。
