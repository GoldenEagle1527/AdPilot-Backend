# ADR 0006：一接口一份契约，领接口的人先写

状态：accepted（计划期后端自用；**给前端的规格已被 [0019](0019-后端OpenAPI对接.md) 改为 OpenAPI**）

## 决定

- 同一业务里一人写接口、一人写页面，必须先有书面契约。
- 契约是 markdown，最低字段：业务id、文档版本、方法、路径、一句话、请求字段、响应字段、错误情况、变更历史。缺字段表不算可开工。
- 领该接口的人先写；领页面的人只消费；有异议改同一份。
- 现在不上完整 OpenAPI；实现期可从 markdown 长成按业务拆的 OpenAPI。

## 后果

并行的接头是 `modules/<id>/contracts/<endpoint>.md`，不是口头约定，也不是页面里另抄一张字段表。  
接口会改：当前正文即最新表；模块 `最新表.md` + 变更历史 + 破坏性 `_history/` 快照，见 ADR 0011。
