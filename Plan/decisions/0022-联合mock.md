# ADR 0022：本地 mock 收成一份联合脚本

状态：accepted

## 决定

1. `oceanengine.mock` 为 true 时，启动只调用一个联合入口灌业务夹具。为 false 时不写这些行。
2. 菜单、角色、部门、本地三个用户仍由现有 `load_seed` 负责。联合脚本不复制菜单。城市分级留在迁移里。
3. 联合脚本按稳定业务键插入或纠正，重复启动不复制行。它要改掉库里已经写错的关系。
4. 当前库已备份在 `.cursor/studio/backups/ad_pilot-20261014.sql`，该目录不进 git。实现不要覆盖这份备份。
