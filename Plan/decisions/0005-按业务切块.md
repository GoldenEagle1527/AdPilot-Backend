# ADR 0005：按业务切块，模块化单体

状态：accepted（权限放哪由 [0008](0008-系统管理模型.md) / [0009](0009-融合系统管理.md) 收口，不再「形状待定」。）

## 决定

- 代码边界跟业务走：一个业务一块，可单独加、单独给人维护。
- 块内再拆到 router 文件；认领可到一个接口。
- 一个 FastAPI 进程，一个业务一个包。不按业务拆可部署服务。
- `core` 只准白名单（启动、配置、日志、错误信封、分页、登录态、CORS、engine/Redis）。
- 授权机器后来落到 `system-admin`（0008/0009），不在本 ADR 展开。

## 后果

新业务只许复制 `Plan/modules/_template/`。实现期禁令见 `outputs/日后规则.md`。  
本仓只提供 API，见 [0012](0012-前后端分两机部署.md)。
