# 日后 Cursor skills（步骤要点）

状态：accepted  
落地 skill：`adpilot-add-module`、`adpilot-add-endpoint`、`adpilot-change-endpoint`。

## S1 — 新建业务块

1. 复制 `Plan/modules/_template/` → `Plan/modules/<id>/`。
2. 改 `说明.md`：职责 + 不自建权限台。
3. 在 `modules/说明.md` 登记。有新入口时在 `system-admin` 菜单树登记节点。
4. 加 FastAPI 包，`main.py` 一行挂载；鉴权只调 `require_menu`。

## S2 — 新建接口

1. 确认业务块已存在。
2. 复制契约模板，填字段与变更历史「初稿」。
3. `最新表.md` 加一行；`后端.md` 加一行。
4. 在该业务包内新增 router，不要放到别的包或 `core`。

## S3 — 变更接口

规则：[architecture/契约版本.md](../architecture/契约版本.md)。

1. 破坏性：先快照 `_history/`。
2. 改正文；文档版本 +1。
3. 变更历史上插一行；更新 `最新表.md`。
4. 实现与最新表不一致 = 未完成。
5. 对外：更新 OpenAPI，发对接文本。

## S4 — 后端框架

已落地，不要再搭一遍。真源：`backend/app/`、`deployment/`、`docker-compose.yml`。
