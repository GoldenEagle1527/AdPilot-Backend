# 日后 Cursor rules（禁令要点）

状态：accepted  
落地文件在 `.cursor/rules/`。

## R1 — 禁止跨业务引用内部实现

业务包不得 import 另一包的内部模型、私有 schema、内部函数。  
例外：其它包可以 import `system_admin` 的公开窄口（`require_menu`、session 查询）。

## R2 — 规格看 OpenAPI

字段以本进程 `/openapi.json` 为准。health / ready 按 [`信封与分页.md`](../architecture/信封与分页.md)。

## R3 — 业务不得进入 core

`core` 只准 [`../architecture/共享白名单.md`](../architecture/共享白名单.md)。

## R4 — 授权只在 system-admin

禁止平行权限码表、第二套权限后台。清单按 xlsx。禁止为清单节点预建投放 CRUD。登录态只属于 core。

## R5 — 新业务必须走模板

复制 `Plan/modules/_template/`。禁止另起目录约定。

## R6 — 改接口必须更新 OpenAPI 并发对接文本

按 [`../backend/接口变更对接.md`](../backend/接口变更对接.md)。禁止在对接文本里贴整份 schema。

## R7 — 本仓只提供 API

禁止用 FastAPI 托管页面。CORS 只放 `core` + yaml。

## R8 — 公司研发规范

[`../meta/公司研发规范.md`](../meta/公司研发规范.md)。

## R9 — 后端栈不得改口

ADR 0014。表模型不得进入 `core`。
