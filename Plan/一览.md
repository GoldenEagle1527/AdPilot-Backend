# 协作与权限一览

给人过一眼的总表。本仓只做后端。细则：`architecture/`、`modules/system-admin/`。  
**框架已落地**（`backend/app/`）。菜单/角色清单按 xlsx（[权限清单-参考.md](modules/system-admin/权限清单-参考.md)）；不要按 102 行预建投放 CRUD。

---

## 1. 模块怎么分

先按**业务**切。一个 FastAPI 进程，一个业务一个 Python 包。

| 模块 | 现在有没有 | 负责什么 | 不负责什么 |
| --- | --- | --- | --- |
| `core` | 已落地 | 启动、配置、信封、分页、CORS、DB/Redis、Header Token | 用户/角色/菜单/业务数据 |
| `system-admin` | 已实现 | 部门、用户、角色、授权机器（树 + 绑定 + 可见部门） | 投放/素材/报表的领域数据 |
| 以后的业务块 | 无，复制 `_template` | 自己的领域表和接口 | 自建一套角色管理 |

| 规则 | 说明 |
| --- | --- |
| 一业务一包 | `app/modules/<business>/` |
| 部门/用户/角色不拆成三个模块 | 并行靠包内 router 文件 |
| 跨模块 | 只调公开契约 / `require_menu`，禁止 import 内部 ORM |
| 新模块 | 只许复制 `Plan/modules/_template/` |

## 2. 本进程怎么对外

本仓 **只跑 API**（ADR 0012）。禁止托管页面、禁止假定浏览器同源。`core` 配 CORS。规格真源是 `/openapi.json`；变更发群对接短文（[backend/接口变更对接.md](backend/接口变更对接.md)）。

`system-admin` 认领面：

| 能力 | 后端文件 |
| --- | --- |
| 部门 | `departments` / `department_tags` / `department_roles` |
| 角色（含勾菜单） | `roles` / `role_menus` / `menu_nodes` |
| 用户（含角色、数据权限、重置密码） | `users` / `user_roles` / `user_data_scope` / `password_reset` |
| 菜单树只读 | `menu_nodes` |
| 壳与其它业务 | `session_queries` + `require_menu` |

## 3. 人怎么领接口

认领：**业务块 → 一个 router 文件**。分支 `feat/<business>/<short>`，合入走 PR。

| 场景 | 怎么做 |
| --- | --- |
| 一人一个接口 | 实现 router，OpenAPI 能看到 |
| 一人多个接口 | 领同一业务里多个 router；一次 PR 仍按接口分开更好 |
| 不要 | 在本仓写页面；改接口不发对接文本 |

## 5. 权限机制

跟截图**同类的机制**。节点清单按 xlsx。投放等业务块仍不预建。

### 5.1 机制总表

| 概念 | 是什么 | 不是什么 |
| --- | --- | --- |
| 用户 | 账号；一人一个所属部门 | 功能权限不写在用户身上 |
| 角色 | 功能权限的容器（名称、备注、启停） | 不是「负责人/成员」 |
| 用户角色 | 给人单独挂的角色 | 不是列表上只读的「部门角色」 |
| 部门角色 | 给部门挂的角色，用户只读继承 | 不是数据权限 |
| 菜单节点 | 目录 / 菜单 / 组件，同一棵树 | 不是权限码表 |
| 数据权限 | 用户勾选的可见部门集合 | 不是所属部门，也不是「全部/仅本人」档位 |

### 5.2 两根轴

| 轴 | 对象 | 绑在谁 | 干什么 |
| --- | --- | --- | --- |
| 功能权限 | 树节点 | 角色 → 用户角色/部门角色到人 | 能不能调对应接口 |
| 数据权限 | 部门 | 直接绑用户 | 业务数据按哪些部门过滤 |

```
用户 ──用户角色──► 角色 ──勾选──► 菜单/组件
  │                  ▲
  ├──所属部门──► 部门角色（只读继承）
  └──数据权限──► 可见部门集合
```

### 5.3 其它业务怎么用

接口里调 `require_menu`；按部门过滤时用可见部门 id。不要自建角色表 / 权限码。有新入口时在 `system-admin` 树上登记节点（数据），不要抄 102 个名称当必须做的 CRUD。
