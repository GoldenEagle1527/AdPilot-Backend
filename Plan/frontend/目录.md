# 前端布局

状态：accepted  
框架：React。实例：[../architecture/融合.md](../architecture/融合.md)。实现期目录在**前端应用仓**根下。

```
src/
  shared/                      白名单
  shells/                      槽位；菜单项来自 system-admin 公开能力
  modules/system-admin/
    pages/departments/
    pages/roles/
    pages/users/
    pages/menu-role-query/
    api/                       只封装本块契约
  modules/<next>/
```

路由建议 `/system-admin/...`（这是**前端机上的页面路由**，不是 API 路径）。系统管理页只调本块契约。壳和未来业务要鉴权数据时调公开能力 B，不调部门/角色 CRUD。

请求打到 **后端机**：基址来自**本仓** yaml，路径和字段拉 OpenAPI。细则：[../architecture/前后端分机.md](../architecture/前后端分机.md)、[../architecture/两仓通信.md](../architecture/两仓通信.md)。搭框架：[搭框架/说明.md](搭框架/说明.md)。

不要按截图复刻布局。
