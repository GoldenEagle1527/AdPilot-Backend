# 前端搭框架：步骤

## 0. 分支

在**前端应用仓**里做。实现期对该仓 `git init`，分支 `feat/framework`。不要往后端仓或当前 `Plan/` 工作区塞 React。

## 1. 脚手架

框架已定 **React**。用 Vite + React（均为 MIT）。按 [`../目录.md`](../目录.md) 建：

```
许可证.md
src/shared/
src/shells/
src/modules/system-admin/
```

不要再开「选框架」ADR。

## 2. 跨机请求

1. API 基址从配置读（与 `deployment/dev.yaml` 的 `api_base` 对齐，或前端一份 yaml）。禁止写进组件。
2. 请求带 **Authorization Header**（有 token 时）。
3. 按信封文档拆 `ok` / `data` / `error`。规格拉 `{基址}/openapi.json`，不要自抄字段表。
4. `GET {基址}/api/v1/health` 必须能打到**对方电脑上的后端**（后端开防火墙之后）。
5. 把本机前端 origin（如 `http://<你的IP>:5173`）发群，供后端写入 `cors_origins`。
6. **禁止自有业务逻辑**；业务请求全部打后端。

## 3. 壳

空槽。菜单将来自后端有效节点（数据按 xlsx 清单），框架阶段不要写死 102 个路由页面。登录可用 mock。

素材须可商用，记入 `frontend/许可证.md` 或 `素材授权.md`。

## 4. 自检

按 [验收.md](验收.md) 勾选。
