# 后端规则：接口变更必须发对接文本

状态：accepted  
ADR：[0019](../decisions/0019-后端OpenAPI对接.md)

这是**后端仓**落地时要遵守的规则。

## 何时发

只要对外 HTTP 有变化，就发，包括：

- 新接口
- 改路径 / 方法 / 字段 / 含义 / 错误码
- 删接口或字段

只改内部实现、OpenAPI 看起来一样：不必发。

## 发到哪

发**群**（需求也在群/线下）。不要指望调用方去翻你的 Git 记录。

## 文本写什么（短）

不要贴 JSON、不要贴整份 OpenAPI。调用方自己去拉。

```
【对接】YYYY-MM-DD
类型：新增 / 变更 / 删除
接口：METHOD /api/v1/...
一句话：……
拉规格：{API基址}/openapi.json
```

可一次列多条，每条仍是一行接口 + 一句话。

## 后端还要保证

- 进程上的 OpenAPI 与线上行为一致（改了代码却没反映进 schema = 没做完）。
- `/openapi.json` 和 `/docs` 开发环境可从局域网打开（和 health 一样，防火墙要放行）。
- Token 仍只走 Header；信封仍按 [../architecture/信封与分页.md](../architecture/信封与分页.md)。
