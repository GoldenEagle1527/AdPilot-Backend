# 数据层（后端已定）

状态：accepted  
ADR：[0014](../decisions/0014-后端定版.md)。合规：[../meta/公司研发规范.md](../meta/公司研发规范.md)。

| 组件 | 版本 / 选择 | 住哪 |
| --- | --- | --- |
| PostgreSQL | 18.x | 开发：本机 Compose（ADR 0020）；生产：192.168.112.12 |
| 驱动 | asyncpg | `app/core/` 的 engine |
| ORM | SQLAlchemy 2.x asyncio | 模型在业务包，engine 在 core |
| 迁移 | Alembic | `backend/alembic/` |
| Redis | 7.2.x | 开发/生产主机与 PG 同行；连接在 `app/core/` |
| 禁止 | psycopg*、Redis 6/7.4/8、PG 非 18 主版本 | — |

配置（含库地址）只从仓库根 `deployment/*.yaml` 读。业务包 `import` core 的 `get_session` / `get_redis`。禁止业务包自己再开一套引擎。
