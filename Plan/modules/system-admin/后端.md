# 后端：system-admin（设计）

状态：review  
包：`app.modules.system_admin`。切法见 [../../architecture/融合.md](../../architecture/融合.md)。

路径与字段以 [contracts/最新表.md](contracts/最新表.md) 为准。登录在 `app.core`：`POST /api/v1/auth/login`。

## A. 本块 CRUD（系统管理页）

| router 文件 | 契约 | 对应页面能力 |
| --- | --- | --- |
| `departments.py` | list/create/update/set-status departments | 部门管理 |
| `department_tags.py` | list/create department-tags；set-department-tags | 部门管理 · 标签 |
| `department_roles.py` | list/set department-roles | 部门管理 · 分配角色 |
| `roles.py` | list/create/update/set-status roles | 角色管理 |
| `role_menus.py` | get/set role-menus | 角色管理 · 分配菜单 |
| `menu_nodes.py` | list-menu-nodes | 分配菜单 + 权限角色查询 |
| `users.py` | list/create/update/set-status users | 用户管理 |
| `user_tags.py` | list/create user-tags；set-user-tags | 用户管理 · 标签 |
| `user_roles.py` | list/set user-roles | 用户管理 · 分配角色 |
| `user_data_scope.py` | get/set user-data-scope | 用户管理 · 分配数据权限 |
| `password_reset.py` | reset-user-password | 用户管理 · 重置密码 |

## B. 公开能力（壳 + 未来业务）

| 文件 | 契约 / 窄口 | 调用方 |
| --- | --- | --- |
| `session_queries.py` | get-session-me / menus / data-scope | 壳、其它业务包 |
| `deps.py` | `require_menu(...)`（HTTP 不对外） | 其它业务接口 |

允许其它包 import B 窄口。禁止 import `domain/` 里的 ORM。

## 依赖

- `core`：配置、信封、登录主体 id。
- 不依赖投放/素材/报表包。
