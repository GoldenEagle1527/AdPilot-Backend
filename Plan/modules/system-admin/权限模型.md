# 权限模型：system-admin

状态：accepted  
和 [数据模型.md](数据模型.md) 一起读。清单见 [权限清单-参考.md](权限清单-参考.md)（本阶段正式清单，ADR 0016）。

业务用户授权，不是开发者权限。

## 机制

两根轴，不要揉成一种「权限」：

| 轴 | 对象 | 绑在谁身上 | 决定什么 |
| --- | --- | --- | --- |
| 功能权限 | 菜单节点（目录 / 菜单 / 组件） | **角色**，再经角色到人 | 能不能进某个页面、能不能用页内某个组件 |
| 数据权限 | 部门 | **用户**（自定义部门集合） | 业务数据按哪些部门过滤 |

```
用户 ──用户角色──► 角色 ──勾选──► 菜单/组件
  │                  ▲
  ├──所属部门──► 部门角色（只读继承）
  └──数据权限──► 可见部门集合
```

- 有效功能权限 = **用户角色菜单 ∪ 部门角色菜单**（节点去重）。负责人/成员不改变这个并集。
- 用户可挂**多个**角色。取消 = 删用户角色关系。
- 数据权限：勾父部门 = 选中全部子孙。空集合 = **仅本人**。多来源冲突时取**并集**。
- 没有权限码真源。页内能力用 type=组件 的节点。
- 「权限角色查询」是反查，不是第二种实体。
- 负责人/成员是用户字段 `role_kind`，不是 Role。
