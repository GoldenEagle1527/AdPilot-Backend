# 页面：users（用户管理）

模块：`system-admin`  
代码落点（日后）：`frontend/src/modules/system-admin/pages/users/`  
领谁：未指定

## 干什么

账号主档；给人挂用户角色；勾可见部门；重置密码。

## 调用

| 页面动作 | 契约 | 用到的字段名 |
| --- | --- | --- |
| 组织树（筛人） | [list-departments.md](../contracts/list-departments.md) | query: name, enabled |
| 按部门树筛人 / 列表 | [list-users.md](../contracts/list-users.md) | query: department_id, include_descendants, nickname, login_account, enabled, page, page_size |
| 新增 | [create-user.md](../contracts/create-user.md) | body: nickname, login_account, short_name, password, phone, department_id, remark |
| 修改 | [update-user.md](../contracts/update-user.md) | path: id；body: nickname, short_name, phone, department_id, role_kind, remark |
| 启停 | [set-user-status.md](../contracts/set-user-status.md) | path: id；body: enabled |
| 标签目录 / 新增标签名 | [list-user-tags.md](../contracts/list-user-tags.md)、[create-user-tag.md](../contracts/create-user-tag.md) | body: name |
| 给用户打标签 | [set-user-tags.md](../contracts/set-user-tags.md) | path: id；body: tag_ids |
| 打开分配角色 | [list-user-roles.md](../contracts/list-user-roles.md) | path: id |
| 保存用户角色 | [set-user-roles.md](../contracts/set-user-roles.md) | path: id；body: role_ids |
| 打开分配数据权限 | [get-user-data-scope.md](../contracts/get-user-data-scope.md) | path: id |
| 保存数据权限 | [set-user-data-scope.md](../contracts/set-user-data-scope.md) | path: id；body: department_ids |
| 重置密码 | [reset-user-password.md](../contracts/reset-user-password.md) | path: id |
