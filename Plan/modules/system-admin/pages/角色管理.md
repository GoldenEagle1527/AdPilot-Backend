# 页面：roles（角色管理）

模块：`system-admin`  
代码落点（日后）：`frontend/src/modules/system-admin/pages/roles/`  
领谁：未指定

## 干什么

角色主数据；给角色勾菜单树。

## 调用

| 页面动作 | 契约 | 用到的字段名 |
| --- | --- | --- |
| 加载/筛选角色 | [list-roles.md](../contracts/list-roles.md) | query: name, enabled, page, page_size |
| 新增 | [create-role.md](../contracts/create-role.md) | body: name, remark |
| 修改 | [update-role.md](../contracts/update-role.md) | path: id；body: name, remark |
| 启停 | [set-role-status.md](../contracts/set-role-status.md) | path: id；body: enabled |
| 打开分配菜单 | [list-menu-nodes.md](../contracts/list-menu-nodes.md)、[get-role-menus.md](../contracts/get-role-menus.md) | query: business_domain, name, include_assigned_roles；path: id |
| 保存勾选 | [set-role-menus.md](../contracts/set-role-menus.md) | path: id；body: menu_ids |
