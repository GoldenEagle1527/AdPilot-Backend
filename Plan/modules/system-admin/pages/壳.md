# 页面：_shell（壳消费公开能力）

模块：`system-admin`（提供） / `shared` 壳（调用）  
代码落点（日后）：`frontend/src/shells/`  
这不是系统管理里的一张业务页。

## 干什么

登录后顶栏/侧栏槽位要知道当前人是谁、能看到哪些菜单。数据来自本块公开能力 B，不写死导航名称。

## 调用

| 壳动作 | 契约 | 用到的字段名 |
| --- | --- | --- |
| 登录提交 | [login.md](../contracts/login.md) | body: login_account, password |
| 取当前用户 | [get-session-me.md](../contracts/get-session-me.md) | （无 query/body；拆 data 展示） |
| 取有效菜单 | [get-session-menus.md](../contracts/get-session-menus.md) | （无 query/body；画槽位用 data.items） |
| 取可见部门（可选） | [get-session-data-scope.md](../contracts/get-session-data-scope.md) | （无 query/body） |
