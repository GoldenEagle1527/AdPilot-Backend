# 页面：departments（部门管理）

模块：`system-admin`  
代码落点（日后）：`frontend/src/modules/system-admin/pages/departments/`  
领谁：未指定

## 干什么

维护部门树：查、增、改、子部门、启停、标签、给部门挂角色。截图只说明能力，不复刻布局。

## 调用

| 页面动作 | 契约 | 用到的字段名 |
| --- | --- | --- |
| 加载/筛选树 | [list-departments.md](../contracts/list-departments.md) | query: name, enabled |
| 新增 / 添加子部门 | [create-department.md](../contracts/create-department.md) | body: name, parent_id, sort |
| 修改 | [update-department.md](../contracts/update-department.md) | path: id；body: name, parent_id, sort |
| 启停 | [set-department-status.md](../contracts/set-department-status.md) | path: id；body: enabled |
| 标签目录 / 新增标签名 | [list-department-tags.md](../contracts/list-department-tags.md)、[create-department-tag.md](../contracts/create-department-tag.md) | body: name |
| 打/摘标签 | [set-department-tags.md](../contracts/set-department-tags.md) | path: id；body: tag_ids |
| 打开分配角色 | [list-department-roles.md](../contracts/list-department-roles.md) | path: id |
| 保存部门角色 | [set-department-roles.md](../contracts/set-department-roles.md) | path: id；body: role_ids |
