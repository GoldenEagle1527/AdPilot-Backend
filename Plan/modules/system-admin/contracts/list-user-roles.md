# 契约：list-user-roles

业务id：system-admin
文档版本：1
方法：GET
路径：/api/v1/system-admin/users/{id}/roles
作用：对该用户的全部角色已分配表；用户角色与部门角色分开。

作者：调度者
状态：accepted
更新日期：2026-09-20

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| id | path | string | 是 | 用户 id |

无请求体。不分页。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| items | RoleBrief[] | **全部角色**各一行。`assigned` 表示是否已挂 **用户角色**（不是部门角色） |
| department_roles | RoleName[] | 只读继承。弹窗里同名角色若仅部门有、用户未挂，则 `items` 里 `assigned=false` |

## 错误

无本接口特有。用户不存在走 404。共用码见 [说明.md](说明.md)。

| --- | --- |
| 用户管理 | 打开分配角色 |
