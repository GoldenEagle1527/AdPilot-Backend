# 契约：get-role-menus

业务id：system-admin
文档版本：1
方法：GET
路径：/api/v1/system-admin/roles/{id}/menus
作用：返回某角色已勾选的菜单节点 id，供分配菜单回填。

作者：调度者
状态：accepted
更新日期：2026-09-20

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| id | path | string | 是 | 角色 id |

无请求体。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| menu_ids | string[] | 该角色已勾选的节点（含菜单与组件）。是否含目录：实现返回实际勾选的 id，调用方不要自己展开 |

## 错误

无特有。共用错误码见 [说明.md](说明.md)。角色不存在走 404 `NOT_FOUND`。

## 被谁调用

| 调用方 | 动作 |
| --- | --- |
| 角色管理 | 打开分配菜单（回填勾选） |
