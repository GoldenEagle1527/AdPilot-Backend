# 契约：add-user-tags

业务id：system-admin
文档版本：1
方法：PUT
路径：/api/v1/system-admin/users/batch-tags
作用：给多个用户**追加**标签（已有的保留）。

作者：调度者
状态：accepted
更新日期：2026-09-20

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| user_ids | body | string[] | 是 | 至少 1 个 |
| tag_ids | body | string[] | 是 | 至少 1 个 |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| items | `{ id, tags: Tag[] }[]` | 每个用户追加后的标签 |
