# 契约：set-user-tags

业务id：system-admin
文档版本：1
方法：PUT
路径：/api/v1/system-admin/users/{id}/tags
作用：整集替换用户上的标签；空数组清空。

作者：调度者
状态：accepted
更新日期：2026-09-20

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| id | path | string | 是 | 用户 id |
| tag_ids | body | string[] | 是 | 整集替换，不是增量。空数组 = 清空 |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 用户 id |
| tags | Tag[] | 写入后的用户标签 |

## 错误

无本接口特有错误。标签不存在走共用 `404 NOT_FOUND`。共用码见 [说明.md](说明.md)。
