# 契约：reset-user-password

业务id：system-admin
文档版本：1
方法：POST
路径：/api/v1/system-admin/users/{id}/password-reset
作用：把密码重置为字典配置的默认密码（Q-PERM-5），不写死 `135`。

作者：调度者
状态：accepted
更新日期：2026-09-20

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| id | path | string | 是 | 用户 id |

无请求体。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| reset | boolean | 成功时为 `true` |
| password | string | 本次生效的默认明文，仅此响应返回一次，便于管理员告知用户 |

## 错误

无本接口特有。共用码见 [说明.md](说明.md)。

| --- | --- |
