# 契约：get-user-data-scope

业务id：system-admin
文档版本：1
方法：GET
路径：/api/v1/system-admin/users/{id}/data-scope
作用：读取用户自定义可见部门 id。与所属部门独立。无「全部 / 本部门及以下 / 仅本人」档位。

作者：调度者
状态：accepted
更新日期：2026-09-20

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| id | path | string | 是 | 用户 id |

无请求体。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| department_ids | string[] | 自定义集合。空数组 = 无按部门隔离的数据权限（不是「全部部门」） |

## 错误

无本接口特有。共用码见 [说明.md](说明.md)。
