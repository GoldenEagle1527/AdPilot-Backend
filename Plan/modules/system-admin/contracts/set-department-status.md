# 契约：set-department-status

业务id：system-admin
文档版本：2
方法：PATCH
路径：/api/v1/system-admin/departments/{id}/status
作用：部门启停。停用后不能再往该部门加人、不能把它当父部门；数据范围与部门角色授权不再计入该部门。已在部门里的人仍可登录。

作者：调度者
