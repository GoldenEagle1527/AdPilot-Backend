# 业务：`uni-template`

状态：draft  
所有者：未指定  
对照包名：`app.modules.uni_template`

## 一句话

全域模板管理：模板全员投手可见，每个投手把自己的全域抖音号挂到模板上。不创建漫剧全域投放任务。

## 权限

不自建角色管理 / 分配菜单 / 数据范围后台。入口对应菜单树节点「智能投放/全域模板管理」。接口只认登录态。模板不按投手隔离；抖音号分配只读写当前登录投手自己的行。

## 表

| 表 | 说明 |
| --- | --- |
| `delivery_template` | 与标准投放共用。`delivery_mode=uni` 才是全域模板。共用名称、主体、变现模式、时间、软删。全域列是项目预算、ROI 系数、AIGC 动态创意、标题选择。标准列在全域行上为空 |
| `delivery_template_douyin` | 投手、模板、全域抖音号。替换时只动当前投手的行 |

抖音号用已有的 `douyin_account.delivery_mode=uni`，并且 `douyin_pitcher` 里已经分给当前投手。标准号不能分配。
