# 契约：batch-create-titles

业务id：material
文档版本：3
方法：POST
路径：/api/v1/material/titles
作用：在一个标题分类下批量新增素材标题。上传者取当前登录用户，上传时间取落库时间。

作者：
状态：draft
更新日期：2026-09-23

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| titles | body | string[] | 是 | 标题名。每条去首尾空白，1–512 字；一次 1–200 条；本批内不得重名 |
| category | body | string | 是 | 标题分类：`paid` 付费标题、`common` 通用标题 |

需 `Authorization: Bearer`。接口层不校验菜单节点，登录即可调。

一批标题共用一个分类。本批内去空白后重名返回 422。**自己**在该分类下已存在任一同名标题时，整批不写，返回 409；判重只看当前登录用户名下的标题，别人用同名不影响。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| created | integer | 新增条数。整批成功才返回，等于请求里的标题数 |

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 422 | `titles: 标题名不能重复` | 本批内重名 |
| 422 | `titles: 标题名不能为空` | 标题为空白、条数超 200、分类不是 `paid`/`common` 等入参不合规 |
| 409 | `2 条标题已存在：甲、乙` | 自己在该分类下已有同名标题，最多列出 5 条 |

其余共用错误见 [说明.md](说明.md)。
