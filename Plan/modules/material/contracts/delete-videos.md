# 契约：delete-videos

业务id：material
文档版本：1
方法：DELETE
路径：/api/v1/material/videos/{video_id}
作用：软删一条视频素材。只能删自己上传的；别人的和已删的按不存在处理。

作者：
状态：draft
更新日期：2026-09-24

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| video_id | path | integer | 是 | 视频素材主键 |

无请求体。需 `Authorization: Bearer`。接口层不校验菜单节点，登录即可调；能删哪条由「只能是自己上传的」决定。

别人上传的、已软删的、或不存在的，一律返回 404，不区分「无权」以免泄露存在性。

只标 `material_videos` 这一行已删除。标签和投手关联行保留，列表不再返回这条素材。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 被删的素材 id |
| deleted | boolean | 恒为 `true` |

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 422 | `video_id: Input should be a valid integer` | 路径不是整数 |
| 404 | `视频素材不存在` | 素材不存在、已软删、或不是自己上传的 |

其余共用错误见 [说明.md](说明.md)。
