# 契约：batch-share-videos

业务id：material
文档版本：1
方法：POST
路径：/api/v1/material/videos/batch-shares
作用：把同一批人加到自己上传的多条素材上。已共享的跳过，不取消原有共享。

作者：
状态：draft
更新日期：2026-09-24

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| video_ids | body | integer[] | 是 | 要共享的视频素材 id。至少 1 个，不得重复。必须都是自己上传且未删除的 |
| user_ids | body | integer[] | 是 | 要共享给的用户。至少 1 个，不得重复。人数不设上限。取消过又出现的恢复 |

需 `Authorization: Bearer`。接口层不校验菜单节点，登录即可调。只有上传者能调。

这是往现有共享上加人，不是单条接口那种完整名单替换。名单里没有的原共享人保留。

有一条素材对不上，或有一个用户不存在，整批不写。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ids | string[] | 素材 id，顺序与传入的 `video_ids` 一致 |
| user_ids | string[] | 这次提交的共享人，顺序与传入一致 |

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 422 | `video_ids: 视频不能重复` | 空数组、重复 id、缺字段、多传字段 |
| 422 | `user_ids: 共享人不能重复` | 共享人重复或为空 |
| 404 | `视频素材不存在：9` | 有素材不存在、已软删、或不是自己上传的 |
| 404 | `用户不存在：9` | `user_ids` 里有用户查不到，报出缺的 id |

## 被谁调用

| 调用方 | 动作 |
| --- | --- |
| 素材管理/视频 | 勾选后批量共享 |
