# 契约：batch-assign-video-pitchers

业务id：material
文档版本：1
方法：POST
路径：/api/v1/material/videos/batch-pitchers
作用：把同一批投手加到多条素材上，记在当前操作人名下。别人分出去的投手不动。

作者：
状态：draft
更新日期：2026-09-24

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| video_ids | body | integer[] | 是 | 要分配的视频素材 id。至少 1 个，不得重复。每条都须是自己上传的，或仍共享给自己 |
| user_ids | body | integer[] | 是 | 要分给的投手。至少 1 个，最多 50 个，不得重复。这个人已经分过的跳过，取消过又出现的恢复 |

需 `Authorization: Bearer`。接口层不校验菜单节点，登录即可调。上传者，或这条素材当前共享人，可以调。

这是在当前操作人自己的投手名单上加人，不是单条接口那种完整名单替换。不取消他原来分过的投手，也不动其他操作人分过的投手。

有一条素材不能操作，或有一个用户不存在，整批不写。不能操作的按素材不存在返回，不区分「无权」。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ids | string[] | 素材 id，顺序与传入的 `video_ids` 一致 |
| user_ids | string[] | 这次提交的投手，顺序与传入一致 |

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 422 | `video_ids: 视频不能重复` | 空数组、重复 id、缺字段、多传字段 |
| 422 | `user_ids: 投手不能重复` | 投手重复、为空，或超过 50 个 |
| 404 | `视频素材不存在：9` | 有素材不存在、已软删，或当前用户既不是上传者也不是共享人 |
| 404 | `用户不存在：9` | `user_ids` 里有用户查不到，报出缺的 id |

## 被谁调用

| 调用方 | 动作 |
| --- | --- |
| 素材管理/视频 | 勾选后批量设置投手归属 |

## 明确不做

- 用这一次名单替换这个人在每条素材上的全部投手（那是单条 `POST /videos/{video_id}/pitchers`）
- 改其他操作人已经分出去的投手
