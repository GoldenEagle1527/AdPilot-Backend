# 契约：assign-video-pitchers

业务id：material
文档版本：1
方法：POST
路径：/api/v1/material/videos/{video_id}/pitchers
作用：上传者或仍在共享里的人，把这条素材分给投手。已经由这个人分过的投手跳过，不删别人分的。

作者：
状态：draft
更新日期：2026-09-24

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| video_id | path | integer | 是 | 视频素材主键 |
| pitcher_ids | body | integer[] | 是 | 投手用户 id。一次 1–50 个，**不得重复**，重复返回 422。此人已经分过的跳过 |

需 `Authorization: Bearer`。接口层不校验菜单节点，登录即可调。能分配的人是上传者，或 `material_video_shares` 里还没被取消的那个人。其他人按素材不存在处理。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 素材 id |
| pitchers | object[] | 这次请求里的投手，按传入顺序。每项 `{ id, nickname }` |

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 422 | `pitcher_ids: 投手不能重复` | 同一次提交里投手 id 重复、数组为空或超 50、多传字段 |
| 404 | `视频素材不存在` | 素材不存在、已软删，或当前用户不是上传者、也不在共享里 |
| 404 | `用户不存在：9` | `pitcher_ids` 里有用户查不到，报出缺的 id |

其余共用错误见 [说明.md](说明.md)。
