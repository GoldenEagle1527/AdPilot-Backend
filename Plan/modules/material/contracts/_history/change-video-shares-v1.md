# 契约：change-video-shares

业务id：material
文档版本：1
方法：POST
路径：/api/v1/material/videos/{video_id}/shares
作用：上传者一次添加和取消素材共享。取消只软删共享行，这个人已经分出去的投手保留。

作者：
状态：draft
更新日期：2026-09-24

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| video_id | path | integer | 是 | 视频素材主键 |
| add_user_ids | body | integer[] | 否 | 要共享给的用户。缺省空数组，一次最多 50 个，不得重复。已共享的跳过，取消过的恢复 |
| remove_user_ids | body | integer[] | 否 | 要取消共享的用户。缺省空数组，一次最多 50 个，不得重复。当前没共享的跳过 |

两个数组不能都空，不能内部重复，也不能有同一个 id。需 `Authorization: Bearer`。接口层不校验菜单节点，登录即可调。只有上传者能调。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 素材 id |
| added | object[] | 这次真正新共享或恢复的人，按传入顺序。每项 `{ id, nickname }` |
| removed | object[] | 这次真正取消的人，按传入顺序。每项 `{ id, nickname }` |

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 422 | `至少指定要添加或取消的共享人` | 两个数组都空、内部重复、同一个人两边都有、超过 50 个、多传字段 |
| 404 | `视频素材不存在` | 素材不存在、已软删，或不是自己上传的 |
| 404 | `用户不存在：9` | `add_user_ids` 里有用户查不到，报出缺的 id |

## 被谁调用

| 调用方 | 动作 |
| --- | --- |
| 素材管理/视频 | 上传者添加或取消共享 |

## 明确不做

- 取消共享时连带删掉这个人分过的投手
