# 契约：assign-douyin

业务id：oceanengine
文档版本：1
方法：POST
路径：/api/v1/oceanengine/douyin/{id}/assign
作用：覆盖保存一个全域抖音号上的投手。标准号拒绝。

作者：
状态：draft
更新日期：2026-09-23

## 请求

JSON，`extra=forbid`。

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| Authorization | header | string | 是 | `Bearer <token>`。菜单 `67` 或 `66` |
| id | path | int | 是 | 本库主键 |
| pitcher_user_ids | body | int[] | 是 | 多选。保存后该号的投手集合就是这份名单。空数组表示该号不再挂投手 |

名单中的用户须带投手标签、未删除且启用，否则 422。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int | |
| pitcher_user_ids | int[] | 保存后的集合 |

不修改 `department_id`、`owner_user_id`。

## 错误

| 情况 | HTTP 状态 | 说明 |
| --- | --- | --- |
| 未登录 | 401 | |
| 无菜单 67 且无菜单 66 | 403 | |
| 不存在或已软删 | 404 | |
| 标准号 | 422 | 标准模式拒绝投手分配 |
| 名单里有人不是可用投手 | 422 | 整次不改 |

## 业务规则

- 仅全域号。标准号不出现在本接口的成功路径里。
- 覆盖的是这一个号自己的投手集合。不改部门与负责人；那是回收接口的事。
- 一个投手可以同时出现在多个全域号上。本接口不做「一个投手只能挂一个号」的限制。

## 被谁调用

全域抖音号分配弹窗。只开了抖音号页（菜单 66）的人也可以保存。
