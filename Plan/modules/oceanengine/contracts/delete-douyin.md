# 契约：delete-douyin

业务id：oceanengine
文档版本：1
方法：DELETE
路径：/api/v1/oceanengine/douyin/{id}
作用：软删抖音号。有执行中计划则拒绝。

作者：
状态：draft
更新日期：2026-09-23

## 请求

无请求体。

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| Authorization | header | string | 是 | `Bearer <token>`。菜单节点 `66` |
| id | path | int | 是 | 本库主键 |

## 响应

成功 `data` 为 null。HTTP 仍是 200，`code` 200。行 `is_deleted=1`，列表不再返回。

## 错误

| 情况 | HTTP 状态 | 说明 |
| --- | --- | --- |
| 未登录 | 401 | |
| 无菜单 66 | 403 | |
| 不存在或已软删 | 404 | |
| 该号有 `opt_status=ENABLE` 且未删除的广告 | 409 | `message` 为 `存在执行中的广告：` 接计划名（空名用 `promotion_id`，顿号分隔）。不软删 |

## 业务规则

删除是软删，占用检查与回收相同：有执行中计划则整次 409。标准号与全域号都走这条。

## 被谁调用

抖音号管理页的删除。
