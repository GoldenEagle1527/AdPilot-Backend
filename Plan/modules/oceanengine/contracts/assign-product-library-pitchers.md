# 契约：assign-product-library-pitchers

业务id：oceanengine
文档版本：1
方法：POST
路径：/api/v1/oceanengine/product-libraries/{id}/assign-pitchers
作用：用一份投手名单覆盖该标准库的投手集合。

作者：
状态：draft
更新日期：2026-09-23

## 请求

JSON，`extra=forbid`。

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| Authorization | header | string | 是 | `Bearer <token>`。菜单节点 `68` |
| id | path | int | 是 | 商品库本库主键 |
| pitcher_user_ids | body | int[] | 是 | 多选。保存后该库投手就是这份名单。空数组表示该库不再挂投手 |

名单中的用户须带投手标签、未删除且启用。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int | |
| pitcher_user_ids | int[] | 覆盖后的集合 |

从本库名单去掉的投手不再挂这个标准库，之后上传走该组织该类型的兜底库。本接口不把他们写进别的标准库。

## 错误

| 情况 | HTTP 状态 | 说明 |
| --- | --- | --- |
| 未登录 | 401 | |
| 无菜单 68 | 403 | |
| 库不存在或已软删 | 404 | |
| 名单里有人不是可用投手 | 422 | 整批不改 |
| 目标库是 `fallback` | 409 | 兜底库不能分配投手。整批不改 |
| 名单中任何人已挂在同一组织、同一 `library_kind` 的另一个标准库上 | 409 | 整批 409，一行都不改 |

## 业务规则

- 只接受标准库。覆盖的是这一个库的投手集合。
- 已经在本库的人不算冲突。冲突只发生在「同一组织、同一 `library_kind` 的其它标准库」。
- 须先在原库的分配里去掉该投手，再写入新库。本接口不会把人从原库挪到新库。
- 视频库与小说库互不影响。别的组织也不占用这个名额。
- 同一组织、同一 `library_kind` 下，一个投手只能在一个标准库。
- 挂了该组织该类型标准库的投手，短剧只进那一个库。没挂的进兜底库。没有兜底库时上传 409，文案 `缺少兜底库`。

## 被谁调用

商品库管理页的分配投手。
