# 业务：`report`

状态：draft  
所有者：未指定  
对照包名：`app.modules.report`

## 一句话

数据报表：漫剧报表（R1IAP、R1IAA 及其项目/计划下钻）和漫剧全域报表（短剧收益、投手短剧收益、投手报表、组报表）的只读查询。读快照，不调巨量。不负责利润报表、素材报表、起量工具。

口径以 [../../product/数据报表/口径.md](../../product/数据报表/口径.md) 为准，本块文档不重复口径。

## 权限

不自建角色管理 / 分配菜单 / 数据范围后台。入口对应菜单树节点：

| 节点 id | 菜单 | 页面 |
| --- | --- | --- |
| 9 | 数据报表/漫剧报表/(付费)端原生短剧报表 | R1IAP → IAP项目 → IAP计划 |
| 5 | 数据报表/漫剧报表/(免费)端原生短剧报表 | R1IAA → IAA项目 → IAA计划 |
| 13 | 数据报表/漫剧全域报表/短剧报表 | 短剧收益、投手短剧收益 |
| 14 | 数据报表/漫剧全域报表/投手报表 | 投手报表 |
| 15 | 数据报表/漫剧全域报表/组报表 | 组报表 |

组报表以外：当前用户姓名在投手里才可见该行。组报表：按数据范围看部门，范围为空只看本部门。
