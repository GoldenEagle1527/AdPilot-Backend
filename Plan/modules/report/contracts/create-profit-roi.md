# 契约：create-profit-roi

业务id：report
文档版本：1
方法：POST
路径：/api/v1/reports/profit/roi
作用：新增一条 ROI 系数。

作者：
状态：draft
更新日期：2026-10-13

## 请求

Header `Authorization`，要菜单 23。Body：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| date_start | string | 是 | `YYYY-MM-DD` |
| date_end | string | 是 | 不能早于起日 |
| roi_rate | number | 是 | 大于等于 0，最多两位小数 |

日期可以和已有配置重叠。读取时取创建时间最新的一条。没被任何配置覆盖的统计日按 1.00。

## 响应

`data` 是刚写入的一条，字段同列表项。
