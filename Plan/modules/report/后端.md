## 依赖的其他业务

| 业务 | 使用的公开接口（契约路径） |
| --- | --- |
| oceanengine | 巨量报表快照（项目、计划、全域 `UNI_PROJECT_DATA`）。报表接口只读快照，不在请求里调巨量 |
| standard-delivery | 漫剧任务的投手、存项目时间、面板，经 `delivery_task_project.ocean_project_id` 和 `delivery_task_promotion.ocean_promotion_id` 匹配 |
| uni-native-task | 全域任务的投手、提交时间，经 `uni_native_task_account.ocean_project_id` 和 promotion id 匹配 |
| theater | 剧目类型（应用风格 `live_action` / `manhua`）、剧场平台（鸥溪） |
| material | 剧目 `publish_time`，判新/老剧 |
| system-admin | 当前用户姓名、所在部门、数据范围 |
