# 巨量广告接口

| 接口 | 契约 |
| --- | --- |
| `GET /api/v1/ocean-ads/accounts` | [list-accounts.md](list-accounts.md) |
| `GET /api/v1/ocean-ads/columns` | [columns.md](columns.md) |
| `PUT /api/v1/ocean-ads/columns` | [columns.md](columns.md) |
| `GET /api/v1/ocean-ads/projects` | 分页查询项目。标准和全域都包含。带收益、比率、转化成本和激活成本。`promotion_links` 是该项目下未删除广告的完整链接 |
| `POST /api/v1/ocean-ads/projects/batch` | [batch-projects.md](batch-projects.md) |
| `POST /api/v1/ocean-ads/projects/budget` | [update-project-budgets.md](update-project-budgets.md) |
| `GET /api/v1/ocean-ads/promotions` | [list-promotions.md](list-promotions.md) |
| `POST /api/v1/ocean-ads/promotions/batch` | [batch-promotions.md](batch-promotions.md) |
| `GET /api/v1/ocean-ads/promotion-names` | 广告名称下拉。一个名称对应一条广告 |
| `GET /api/v1/ocean-ads/materials` | 按选定的一天加总素材。带点击率、点击单价、转化成本和转化率 |
| `GET /api/v1/ocean-ads/uni-projects` | 只列出全域项目。`roi_goal` 向巨量项目列表要 |
