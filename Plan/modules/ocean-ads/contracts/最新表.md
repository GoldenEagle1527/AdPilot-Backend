# 巨量广告接口

返回里的巨量、常读 id 一律是字符串，不再是数字。这些 id 最长 19 位，超出 JS 数字能精确表示的范围。批量接口正文里的 id 传字符串或数字都接受。本库自己的 id（如 `video_id`、`pitcher_user_id`）仍是数字。2026-10-14 起。

| 接口 | 契约 |
| --- | --- |
| `GET /api/v1/ocean-ads/accounts` | [list-accounts.md](list-accounts.md)（v3：`account_id` 改字符串） |
| `GET /api/v1/ocean-ads/columns` | [columns.md](columns.md) |
| `PUT /api/v1/ocean-ads/columns` | [columns.md](columns.md) |
| `GET /api/v1/ocean-ads/projects` | 分页查询项目。标准和全域都包含。带收益、比率、转化成本和激活成本。`promotion_links` 是该项目下未删除广告的完整链接。`project_id`、`account_id` 是字符串 |
| `POST /api/v1/ocean-ads/projects/batch` | [batch-projects.md](batch-projects.md)（v2：id 改字符串） |
| `POST /api/v1/ocean-ads/projects/budget` | [update-project-budgets.md](update-project-budgets.md)（v2：id 改字符串） |
| `GET /api/v1/ocean-ads/promotions` | [list-promotions.md](list-promotions.md)（v2：id 改字符串） |
| `POST /api/v1/ocean-ads/promotions/batch` | [batch-promotions.md](batch-promotions.md)（v2：id 改字符串） |
| `GET /api/v1/ocean-ads/promotion-names` | 广告名称下拉。一个名称对应一条广告 |
| `GET /api/v1/ocean-ads/materials` | 按选定的一天加总素材。带点击率、点击单价、转化成本和转化率。`material_id`、`promotion_id`、`project_id`、`account_id` 是字符串，`video_id` 仍是数字 |
| `GET /api/v1/ocean-ads/uni-projects` | 只列出全域项目。`roi_goal` 向巨量项目列表要。`project_id`、`account_id` 是字符串 |
