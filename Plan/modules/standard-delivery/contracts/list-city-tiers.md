# 契约：list-city-tiers

业务id：standard-delivery
文档版本：1
方法：GET
路径：/api/v1/standard-delivery/city-tiers
作用：给免费、付费端原生模板的发展划分提供城市分级。编码是巨量行政信息的市级 code。

作者：
状态：draft
更新日期：2026-10-12

## 请求

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| Authorization | header | string | 是 | `Bearer <token>`。模板菜单 `45` 或 `50` 至少有一个 |

## 响应

`data.items[]`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tier | string | `一线`、`新一线`、`二线`、`三线`、`四线`、`五线`。顺序固定 |
| cities | array | `{ "ocean_code", "name" }`。`ocean_code` 是巨量市级 code，创建项目时放入 `audience.city`。`name` 是巨量返回的城市名 |

分级来自百度百科《中国城市新分级名单》词条正文。同一城市后文又出现时，保留先出现的等级。青海的海南藏族自治州在巨量侧的名称是「海南州」。

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 401 | `未带或 Token 无效` | 未登录 |
| 403 | `已登录但无对应菜单或组件` | 没有免费或付费模板菜单 |
