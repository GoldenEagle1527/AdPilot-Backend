# 本业务的接口契约

- 每个真实接口一份 `<endpoint-id>.md`。正文里的请求/响应表就是最新表。
- 模块总目录：[最新表.md](最新表.md)。
- 破坏性变更快照：[_history/](_history/说明.md)。

字段与版本规则：[../../../architecture/契约版本.md](../../../architecture/契约版本.md)。

全站信封是 `{ "code", "message", "data" }`。成功 `code` 为 200。分页 `data` 为 `list` / `total` / `page` / `page_size`。未登录 401，没有对应菜单 403，校验失败 422。

本地主键在出参里是字符串。金额是两位小数字符串，回收率是四位小数字符串。时间是北京时间 `+08:00`，精确到秒。
