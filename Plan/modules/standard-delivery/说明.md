# 业务：`standard-delivery`

状态：draft  
对照包名：`app.modules.standard_delivery`

## 一句话

漫剧标准投放在本系统里保存模板、投放任务草稿和自动投放规则，并按免费/付费、名称、主体、短剧等筛选。确认提交读已保存的草稿，经已装上的客户端建项目、传商品和主图，报文留在返回值里。

## 权限

登录后 `Authorization: Bearer`。免费和付费各用自己的菜单，没有对应菜单返回 403。

| 页面 | 免费菜单 | 付费菜单 |
| --- | --- | --- |
| 模板 | 45 | 50 |
| 投放任务草稿 | 39 | 46 |
| 自动投放规则 | 51 | 52 |

草稿和规则只返回当前登录投手自己的行。模板按收费模式共用，不按投手拆。

抖音号下拉用已有的标准号：`douyin_account.delivery_mode=standard` 且 `enabled=true`。全员共用，不读 `douyin_pitcher`。一次草稿只有一个 `aweme_id`，账户列表共用它。

## 表

| 表 | 说明 |
| --- | --- |
| `delivery_template` | 与全域模板共用。本模块只读写 `delivery_mode=standard`。全域列在标准行上为空。未删除重名按 `(delivery_mode, charge_mode, name)` |
| `delivery_task_draft` | 任务草稿。预约、一个抖音号、一部短剧、版位、项目/广告预算、优化目标、商品库、手填专辑链接、项目/广告开关 |
| `delivery_task_account` | 草稿上的广告账户。请求用巨量广告主 id |
| `delivery_task_video` | 草稿上的视频素材 id。不建数据库外键 |
| `delivery_task_title` | 草稿上的标题 id。不建数据库外键 |
| `delivery_auto_rule` | 规则名称、模板、每部剧账户数、每部剧最大视频数、预约、消耗、回收、上架日期、是否只针对最大转化 |
| `delivery_auto_rule_series` | 规则选中的短剧，可多选 |

## 下拉用的现成数据

| 字段 | 来源 |
| --- | --- |
| 账户 | `advertiser_account`，须是当前投手的有效户。请求里的 `advertiser_ids` 是巨量广告主 id |
| 主体 | `delivery_subject`，须 `delivery_mode=standard`，收费模式与模板一致 |
| 抖音号 | 已启用的 `douyin_account.delivery_mode=standard` |
| 商品库 | `product_library.library_no`。标准库还要分给当前投手，兜底库可用 |
| 短剧 | `manhua_series` |
| 视频 | `material_videos`，须属于所选短剧且当前用户能看见 |
| 标题 | `material_titles`，只收当前用户自己上传的 |

## 这轮不落库的字段

下面这些接口不收、表里也不留：

| 产品里的字段 | 原因 |
| --- | --- |
| `optimize_goal.asset_ids` | 没有事件资产 id。确认提交这次不要加 |
| 地域、城市 | 这次提交按不限：`district=NONE`，不传 city，不落库 |
| 短剧对应的巨量商品 id | 草稿仍只存商品库。商品上传另走 oceanengine |
| 产品主图 id | 不写在模板上。主图走 `POST /api/v1/oceanengine/images` |
| 巨量 `video_id` | 草稿只存 `material_videos.id`。素材表存的是文件地址 |
| 自动规则的剧场 | `manhua_series` 没有剧场外键。短剧来自漫剧库，不另存「番茄漫剧」 |

专辑链接存在草稿 `album_url`，是手填的一条 URL，不是剧场推广链。产品名称、卖点、行动号召在标准模板上。

视频 id、标题 id 不做数据库外键：`material_videos` / `material_titles` 不在现有迁移链里，当前这个本地库也还没有这两张表。保存时仍会查这两张表。
