# 业务：`uni-native-task`

状态：draft  
所有者：未指定  
对照包名：`app.modules.uni_native_task`

## 一句话

漫剧全域投放的端原生投放任务在本系统保存。确认提交经已装上的客户端建项目、传商品和主图。状态保持已保存，不把素材标成传完，也不做端原生自动化投放。

## 权限

不自建角色管理 / 分配菜单 / 数据范围后台。入口对应菜单树节点「智能投放/漫剧全域投放/端原生投放任务」。接口只认登录态。列表、详情、修改、删除、确认提交都只碰当前登录投手自己的任务。

## 表

| 表 | 说明 |
| --- | --- |
| `uni_native_task` | 任务。存 `template_id`，以及从全域模板抄来、可被本次提交覆盖的项目预算和 ROI。状态只有 `saved`。`executed_at` 为空 |
| `uni_native_task_account` | 抖音号与广告账户一一对应，至少一行 |
| `uni_native_task_link` | 客户端传入的 IAA / IAP 推广链文本。没有剧场外键 |
| `uni_native_task_video` | 视频素材主键。`material_videos` 在库里才校验 |
| `uni_native_task_title` | 标题库主键。`material_titles` 在库里才校验 |
| `uni_native_task_batch_title` | 临时标题。不写入标题库 |

短剧用已有的 `manhua_series`。简称是剧名前两个字，不另存列。抖音号须为 `delivery_mode=uni` 且在 `douyin_pitcher` 里分给当前投手。账户须为当前投手名下的有效广告主。
