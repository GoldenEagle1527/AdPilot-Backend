# 契约：upload-file

业务id：file
文档版本：1
方法：POST
路径：/api/v1/files/upload
作用：接收一个前端文件，转到火山引擎 TOS，返回公网地址。不落库。

作者：
状态：draft
更新日期：2026-09-24

## 请求

`multipart/form-data`。需 `Authorization: Bearer`。接口层不校验菜单节点，登录即可调。

| 字段 | 位置（path/query/body/header） | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| file | body | file | 是 | 文件本体。必须带后缀，内容不能为空 |

对象键由后端生成：`{项目名}/{年}/{月}/{日}/{用户 id}/{文件名}_{uuid}.{后缀}`。项目名取配置 `app_name`（缺省 `adpilot`），日期按北京时间，用户 id 取当前登录用户。文件名是原文件名去掉后缀后的部分；取不到文件名时最后一段只有 `{uuid}.{后缀}`。后缀取原文件名最后一个点之后并转小写。请求体只有 `file`。

## 响应

`data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| url | string | 公网访问地址，可交给只收 url 的接口 |
| key | string | 对象键 |
| original_name | string | 原始文件名，没有则为空串 |
| size | integer | 字节数 |
| content_type | string | 上传声明的类型；没有则按文件名猜，再不行是 `application/octet-stream` |

`message` 为「成功」。

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 400 | `文件缺少后缀` | 文件名没有 `.` 加字母数字后缀 |
| 400 | `文件内容为空` | 读到的字节是空的 |
| 401 | `未带或 Token 无效` | 未登录 |
| 422 | `file: Field required` | 没传 `file` 字段 |
| 503 | `文件上传失败` | TOS 返回的状态不是 200 |

其余共用错误见 [说明.md](说明.md)。

## 被谁调用

| 调用方 | 动作 |
| --- | --- |
| 素材管理/视频 | 先上传文件，再把 `url` 交给添加视频素材 |

## 明确不做

- 一次传多个文件
- 落库、转码、封面与第一帧抽取
