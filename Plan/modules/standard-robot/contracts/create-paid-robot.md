# 契约：create-paid-robot

业务id：standard-robot
文档版本：2
方法：POST
路径：/api/v1/standard-native-robots/paid
作用：新增一条付费漫剧端原生机器人。模板必须是 IAP。不在这次请求里提交投放。

作者：
状态：draft
更新日期：2026-10-13

## 请求

菜单 `77`。字段同 [create-free-robot.md](create-free-robot.md)。`charge_mode` 固定 IAP。

## 响应

字段同免费列表项，`charge_mode` 为 `IAP`。

## 错误

| HTTP | message 示例 | 何时 |
| --- | --- | --- |
| 400 | `机器人须使用付费端原生模板` | 模板不是 IAP |
| 400 | `推广链规则需要剧场平台` | 同免费 |
| 400 | `每天执行需要小时` | 同免费 |
| 404 | `模板不存在` | 模板没有或已删 |
