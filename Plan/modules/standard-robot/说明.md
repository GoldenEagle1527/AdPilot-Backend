# 业务：`standard-robot`

状态：draft  
所有者：未指定  
对照包名：`app.modules.standard_robot`

## 一句话

标准自动投放策略里的免费、付费漫剧端原生机器人。规则按菜单分开保存；到点仍由既有循环建草稿并 mock 提交。

## 权限

菜单 `76` 免费、`77` 付费。列表、修改、删除、开关只动当前登录投手自己的、且收费模式与菜单一致的规则。

## 表

| 表 | 说明 |
| --- | --- |
| `standard_native_robot_rule` | 一条规则。`charge_mode` 为 IAA 或 IAP，`rule_kind` 为 nb、drama、promotion_link |
