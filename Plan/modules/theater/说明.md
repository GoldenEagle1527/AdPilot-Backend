# 业务：`theater`

状态：draft  
所有者：未指定  
对照包名：`app.modules.theater`

## 一句话

三方剧场：平台列表（番茄、鸥溪两个固定平台的开关）和应用列表（创建投放广告时选用的剧场应用）。不负责推广链、番茄推广链接同步、机器人剪辑。

## 权限

不自建角色管理 / 分配菜单 / 数据范围后台。入口是 `system-admin` 菜单树节点「智能投放/全域模板管理/三方剧场/平台列表」「…/应用列表」。平台和应用是全员共用配置，不按部门隔离。

## 表

| 表 | 说明 |
| --- | --- |
| `theater_platforms` | 平台，主键即平台 id（番茄 1、鸥溪 22），不开放新建 |
| `theater_apps` | 应用，`platform_id` 外键指向平台 |
