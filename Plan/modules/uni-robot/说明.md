# 业务：`uni-robot`

状态：draft  
所有者：未指定  
对照包名：`app.modules.uni_robot`

## 一句话

全域漫剧机器人里「按推广链接创建批量任务」和「按剧条件创建批量任务」的规则保存。不负责到点执行，也不创建巨量任务。

## 权限

不自建角色管理 / 分配菜单 / 数据范围后台。入口对应菜单树节点「智能投放/全域模板管理/全域自动投放策略/漫剧机器人」。规则是全员共用配置，接口层只认登录态，不按部门隔离。

## 表

| 表 | 说明 |

| `uni_robot_rule` | 两种规则共用。HTTP 按 `rule_kind` 分开：`promotion_link` 的条件列必须为空，`drama_condition` 必须带统计时间和区间 |
