# 本业务的接口契约

- 每个真实接口：一份 `<endpoint-id>.md`，格式同 [../../_template/contracts/接口契约.模板.md](../../_template/contracts/接口契约.模板.md)。正文里的请求/响应表就是**最新表**。
- 模块总目录：[最新表.md](最新表.md)（一行一个当前接口，不含字段）。
- 破坏性变更快照：[_history/](_history/说明.md)。

字段与版本规则：[../../../contracts/接口模板.md](../../../contracts/接口模板.md)、[../../../architecture/契约版本.md](../../../architecture/契约版本.md)。

全站信封/分页/Token 约定同 [system-admin/contracts/说明.md](../../system-admin/contracts/说明.md) 共用错误码表。本模块时间用北京时间 `+08:00`，精确到秒。

领接口的人先写。改接口的人必须升文档版本、写变更历史、更新 `最新表.md`。
