# 业务：`uni-native-auto-run`

状态：draft  
所有者：未指定  
对照包名：`app.modules.uni_native_auto_run`

## 一句话

漫剧全域投放的端原生自动化投放页面只列出执行记录。记录等漫剧机器人真正跑起来以后再写入。这一块不跑机器人，不手建，也不调巨量。

## 权限

不自建角色管理。入口对应菜单树节点「智能投放/漫剧全域投放/端原生自动化投放」。接口只认登录态，登录用户看全部未删除记录。

## 表

| 表 | 说明 |
| --- | --- |
| `uni_native_auto_run` | 一次执行。`rule_id` 是 `uni_robot_rule.id`。规则名、模板名是当时的快照。`rule_type` 与规则表的 `rule_kind` 相同：`promotion_link`、`drama_condition`。`status` 为 `success` / `failed` / `partial`。`series_names` 是这次跑到的短剧名称 |
| `uni_native_auto_run_failure` | 这次执行的失败日志：短剧名称、原因、创建时间 |

两张表都用全库的软删除列。本模块没有删除接口。包内 `record_run` 给以后的执行器写入，测试也可以调用。启动和 HTTP 不灌假数据。
