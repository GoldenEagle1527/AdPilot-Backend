# 公司研发规范（Drooling 必须遵守）

状态：accepted  
来源：研发部通知；后续会写入《公司研发规范手册》。本文件是计划内真源，手册成文后若有冲突以手册为准并开 ADR 同步。

ADR：[0013](../decisions/0013-公司研发规范.md)

## 1. 禁止非标管理面板

生产服务器（云服务器、本地物理机）**禁止**安装或使用「宝塔」以及任何未经公司官方授权、非标准化的第三方服务器管理面板 / 统一运维平台。

本项目装 PostgreSQL、Redis、反向代理：用发行版官方包或公司 Harbor 镜像，不要走宝塔。

## 2. Redis 版本

必须 **Redis 7.2.x**。禁止 6.x 及更低，禁止擅自升到 7.4.x / 8.x。

## 3. 关系库版本

必须 **PostgreSQL 18.x**。更高主版本等公司评估通知后再动。

## 4. 开源许可证

引入的组件 / 库 / 框架，许可证必须是宽松协议之一：

- MIT
- Apache-2.0
- BSD-3-Clause
- BSD-2-Clause
- ISC

**禁止**未审批引入：GPL、AGPL、LGPL（含静态链接或分发）、EPL 等 Copyleft / 互惠协议。

确需受限协议：书面申请 → 技术 + 法务评审通过 → 备案。未批不得进仓库。

本项目后端驱动因此 **禁止 psycopg / psycopg2**（LGPL），用 `asyncpg`（Apache-2.0）。

搭框架时维护一份依赖许可证表（见各 `搭框架/验收.md`）。新增依赖先核许可证再写入。

## 5. 素材版权

字体、图标、图片、Logo、音视频等：必须是明确开源且允许商用（SIL OFL、CC0、CC-BY 等），或公司自有 / 已获正规商用授权并留证明。禁止未授权或「仅限个人使用」的素材。
