## 认领层级

**现在：** 一人领整个后端框架，一人领整个前端框架。

框架之后仍是：

1. **业务块** — 现在即 `system-admin`；下一块到来再开目录。
2. **端** — 后端机上的 `system_admin` 包 vs 前端机上的 `modules/system-admin` 页面。两端只通过契约 HTTP 通信（ADR 0012）。
3. **文件** — 如只领 `user_data_scope` 接口，或只领用户管理里「分配数据权限」这一能力。

## 同一业务两人并行
