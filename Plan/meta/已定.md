
- 一个 FastAPI 进程，一个业务一个包。

- 两机部署。开发：后端本机开端口；前端对方机器。
- Docker 只打应用；配置 yaml 在 `deployment/`；库用 192.168.112.12 共用实例。
- **两个应用 Git 仓**。产品名 AdPilot。暂无 origin。`Plan/` 只是现在写计划。对接：OpenAPI + 群里对接短文。前端无自有业务逻辑。
- 公司规范：禁宝塔、许可证白名单、素材可商用。
- 权限机制 + **xlsx 清单** + 行为细则（并集、勾父含子、多角色、字典默认密码、租户字段）。
