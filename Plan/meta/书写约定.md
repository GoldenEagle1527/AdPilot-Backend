# 计划书写约定

状态：accepted  
范围：怎么改 `Plan/`。

## 一条事实一个文件

- 已定决定 → [`已定.md`](已定.md) 与 ADR
- 业务怎么切 → `architecture/模块化.md`
- core 准什么 → `architecture/共享白名单.md`
- 单接口契约 → `contracts/接口模板.md`
- 契约版本 → `architecture/契约版本.md`
- 本进程只提供 API → `architecture/前后端分机.md`
- 公司研发规范 → `meta/公司研发规范.md`
- 数据层 → `backend/数据层.md`
- Git → `meta/Git与Gitea.md`、`.cursor/rules/git-branch-pr.mdc`
- 未决 → `未决问题.md`

禁止把已定树复制成第三份正文。

## 业务块

复制 `modules/_template/` 为 `modules/<id>/`。  
`<id>` 与 Python 包、URL 前缀一致（kebab-case；包名 snake_case）。

## 允许改

| 认领 | 可写 | 不可写 |
| --- | --- | --- |
| 某 `modules/<id>/` | 该业务块 | 其他业务；架构原则（除非 ADR） |
| 某接口契约 | `contracts/<endpoint>.md`、`最新表.md`、必要时 `_history/` | 另起一份字段表 |
| 后端实现 | `backend/app/modules/<pkg>/` | 本仓里的前端工程 |

## 语言

正文中文。计划 markdown **文件名**可用中文。目录名、业务 id、代码落点英文。
