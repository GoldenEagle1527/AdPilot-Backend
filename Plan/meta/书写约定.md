# 计划书写约定

状态：accepted  
范围：怎么改 `Plan/`。不管实现期代码。

## 一条事实一个文件

- 已定决定 → [`已定.md`](已定.md) 与 ADR
- 业务怎么切 → `architecture/模块化.md`
- shared 准什么 → `architecture/共享白名单.md`
- 单接口契约形状 → `contracts/接口模板.md`
- 契约最新表与变更历史 → `architecture/契约版本.md`
- 页面调用记录 → `architecture/调用关系.md`
- 前后端两机部署 → `architecture/前后端分机.md`
- 公司研发规范 → `meta/公司研发规范.md`
- 后端定版 → `backend/数据层.md`
- 搭框架执行 → `backend/搭框架/`、`frontend/搭框架/`
- 日后 Cursor 禁令 → `outputs/日后规则.md`
- 未决 → `未决问题.md`

禁止把已定树复制成第三份互相漂的正文。引用用相对链接。

## 业务块

有业务名字之后：复制 `modules/_template/` 为 `modules/<id>/`。  
`<id>` 与日后 Python 包、前端目录、URL 前缀一致（kebab-case；Python 包用下划线）。

未走模板私自另起目录 = 违反已定树（实现期由 rule 拦；现在靠本约定）。

## 允许改

| 认领 | 可写 | 不可写 |
| --- | --- | --- |
| 某 `modules/<id>/` | 该业务块 | 其他业务；架构原则（除非 ADR） |
| 某接口契约 | `modules/<id>/contracts/<endpoint>.md`、`最新表.md`、必要时 `_history/` | 另起一份字段表给前端或写进页面卡片 |
| 某页面卡片 | `modules/<id>/pages/<page>.md` | 复制契约的类型/必填列 |
| 后端搭框架 | `Plan/backend/搭框架/` 与 `backend/` 代码 | 前端代码；业务契约字段 |
| 前端搭框架 | `Plan/frontend/搭框架/` 与 `frontend/` 代码 | 后端代码；未开 ADR 就换框架 |

## 语言

正文中文。计划里的 markdown **文件名**用中文。目录名、业务 id、代码落点仍英文（kebab-case / snake_case）。
