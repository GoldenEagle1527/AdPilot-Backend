# 怎么分给不同的人

状态：accepted  
实例：[融合.md](融合.md)。不要拆 `core`。

## 默认顺序

先按**业务块**，再按**一个接口 / 一个 router 文件**。  
`system-admin` 内部的部门/用户/角色是包内文件，不是三个业务。

## 工作包

| 工作包 | 产出 |
| --- | --- |
| 单接口契约 | `modules/<id>/contracts/<endpoint>.md` + `最新表.md` 一行 |
| 该接口实现 | 该业务包内 router；分支 `feat/<id>/<short>`，PR 合 `main` |
| 新业务块 | 复制 `_template` + `app/modules/<snake>/` |

没有契约字段表，不算实现可开工。改已有契约走 [契约版本.md](契约版本.md)。

## system-admin 认领面

| 人 | 后端文件 |
| --- | --- |
| A | `departments.py` + 部门标签 |
| B | `roles.py` + `role_menus.py` |
| C | `users.py` + `user_roles.py` + `user_data_scope.py` + 重置密码 |
| D | `menu_nodes.py` |
| E | `session_queries.py`（公开能力） |

不要按层拆成「你写全部 schema 我写全部 service」。
