# 信封与分页

状态：accepted  
本进程必须按此实现。改形状 = 破坏性，走契约版本规则并通知调用方。

## 成功

```json
{
  "ok": true,
  "data": {},
  "error": null
}
```

`data` 可以是对象、数组或 `null`。

## 失败

HTTP 状态仍用 4xx/5xx。正文：

```json
{
  "ok": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "给人看的一句话"
  }
}
```

`code` 用大写蛇形。业务错误码以后写在各契约的「错误」表，不要在 `core` 枚举业务名词。

## 分页（列表的 `data`）

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

查询参数：`page`（从 1 起）、`page_size`（默认 20，上限 100）。

时间字段：ISO-8601 UTC 带 `Z`，实现用 `app.core.times.iso8601_z`。主键 string，实现用 `app.core.ids.new_id`。
