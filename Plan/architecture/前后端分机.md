# 本进程只提供 API

状态：accepted  
ADR：[0012](../decisions/0012-前后端分两机部署.md)

本仓一个 FastAPI 进程，一业务一包。调用方在别的机器/别的仓。本仓 **不** 写页面、**不** 托管静态前端。

## 后端必须开 CORS

`core` 用 `deployment/*.yaml` 的 `cors_origins`。不要 `*` 配带 Cookie。业务包不各自写 CORS。调用方把 origin 发群后再写入。

## 登录态

Token 只放 **Authorization Header**（ADR 0016）。登录查库，Token 存 Redis。不要写 Cookie 域。

## 规格

字段与路径的真源是本进程 `/openapi.json`。变更发对接短文：[../backend/接口变更对接.md](../backend/接口变更对接.md)。

## 禁止

- 生产用 FastAPI `StaticFiles` / 模板渲染当正式前端
- 在业务包里写死调用方 IP
- 假定浏览器与 API 同源、只靠相对路径 `/api/...`
