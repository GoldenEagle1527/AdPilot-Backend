# 模块化：一个业务一块

状态：accepted  
实例：[融合.md](融合.md)。本文件只留通则。

## 定义

一个**业务块**可单独加入、单独给人维护：

- 稳定 id（kebab-case）
- 一个后端包、自己的 `contracts/`
- 领域数据住在本块；**不**自建角色管理台

当前已登记：`system-admin`。投放 / 素材 / 报表未开块。

## 权限放哪

| 东西 | 住哪 |
| --- | --- |
| 角色、菜单树、部门数据范围 | `system-admin` |
| 其它业务的领域表 | 各自的业务块 |
| 登录态 | `core` |

## 代码落点

```
backend/app/
  core/
  modules/
    system_admin/
    <next>/
Plan/modules/<business-id>/
```

## 允许的依赖

```
调用方 HTTP     --> 本块契约（本进程）
未来业务包      --> system_admin 公开窄口（require_menu / session）
业务包          --> core
业务包         -x-> 另一包的 ORM / 私有函数
```

`system_admin` 不得反向依赖尚未存在的投放包。

## 新业务准入

复制 [`../modules/_template/`](../modules/_template/)。不要新开「权限」业务块。
