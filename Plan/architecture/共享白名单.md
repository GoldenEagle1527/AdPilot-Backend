# shared 白名单

状态：accepted  
与 [融合.md](融合.md)、[前后端分机.md](前后端分机.md) 一起读。

## 准（`app/core/`）

| 准 | 说明 |
| --- | --- |
| 应用启动、配置 | FastAPI `create_app`；只读 `deployment/*.yaml` |
| CORS 允许源 | yaml 里的调用方 origin。业务包不准各自写 CORS |
| HTTP 错误信封、分页 | [信封与分页.md](信封与分页.md) |
| 时间 `iso8601_z` | 对外时间 UTC `Z`。各包不要再抄一份 |
| 登录态 | **Authorization Header** Token（ADR 0016） |
| DB engine / session / Redis 客户端 | [../backend/数据层.md](../backend/数据层.md)。表模型不准进 core |

认证 ≠ 授权。`core` 只回答「谁来了」。

## 不准

| 不准 | 住哪 |
| --- | --- |
| User / Department / Role / MenuNode | `system-admin` |
| 角色、菜单树、数据范围、分配* | `system-admin` |
| 有效菜单、require_menu | `system_admin` 公开窄口 |
| 投放/素材/报表领域对象 | 尚未开块；开了住各自包 |

不要因为「每个接口都要鉴权」就把授权模型搬进 `core`。不要在本仓做布局槽位或页面。
