# shared 白名单

状态：accepted  
与 [融合.md](融合.md)、[前后端分机.md](前后端分机.md) 一起读。

## 准

| 准 | 说明 |
| --- | --- |
| 应用启动、配置、日志 | FastAPI `create_app`；配置只读 `deployment/*.yaml` |
| CORS 允许源 | 配置里的前端机源列表。业务包不准各自写 CORS |
| HTTP 错误信封、分页形状 | 全站 JSON 外壳，见 [信封与分页.md](信封与分页.md) |
| 登录态怎么带着 | **Authorization Header** 带 Token（ADR 0016）。必须能跨源打到后端机 |
| 布局槽位 | 顶栏/侧栏的空位。**菜单有哪些项问 system-admin 公开能力，不在 shared 写死** |
| 前端：API 基址与请求封装 | 只读配置里的后端基址。禁止写死 IP/域名进业务页。禁止在 shared 写业务规则 |
| DB engine / session / Redis 客户端 | PostgreSQL 18 + Redis 7.2，见 [../backend/数据层.md](../backend/数据层.md)。表模型不准进 core |

认证 ≠ 授权。shared 只回答「谁来了」。

## 不准（system-admin 到来后更明确）

| 不准 | 住哪 |
| --- | --- |
| User / Department / Role / MenuNode | `system-admin` |
| 角色、菜单树、数据范围、分配*、权限角色查询 | `system-admin` |
| 有效菜单计算、require_menu | `system-admin` 公开能力，其它包只调窄口 |
| 投放/素材/报表领域对象 | 尚未开块；开了住各自包 |
| 「其实只有系统管理在用」的工具函数 | 仍留在 `system-admin` |

不要因为「每个页面都要鉴权」就把授权模型搬进 `core`。
