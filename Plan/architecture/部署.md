# 部署

状态：accepted  
ADR：[0017](../decisions/0017-Docker与共用库.md)、[0020](../decisions/0020-本地Docker开发.md)

## 本仓目录

```
deployment/dev.yaml      # listen、cors_origins、postgres、redis
deployment/prod.yaml     # 生产库地址
dockerfile/backend.Dockerfile
docker-compose.yml       # 开发旁路：PG 18、Redis 7.2、API
```

不要在应用 Dockerfile 里 `FROM redis` / `FROM postgres`。

## 环境

进程监听 `0.0.0.0`，端口以 yaml `listen_port` 为准（默认 8000）。局域网访问需放行防火墙。

**开发/测试**：本机 Compose 起 Postgres 18、Redis 7.2 和 API。不要连 192.168.112.12。  
**生产**：才连 192.168.112.12。不要用宝塔。

配置只读本仓 yaml，不用 dotenv。改接口怎么通知：[两仓通信.md](两仓通信.md)。
