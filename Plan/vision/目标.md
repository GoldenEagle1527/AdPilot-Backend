# 目标

状态：accepted

1. **按业务切块**，便于多人维护。第一块是 `system-admin`。
2. **块内再拆**到单个接口 / 单个页面。
3. **并行靠契约**；领接口的人先写。
4. **授权是业务用户的事**：机器在 `system-admin`；其它业务用公开能力，不自建权限台，也不为开发者做一套权限系统。
5. **前后端两机**：两套产物，两台机器，只通过 HTTP 契约通信。
6. **后端定版 + 公司规范**：PG18、Redis 7.2、宽松许可证、禁宝塔。

非目标（现阶段）：系统管理业务功能、复刻截图视觉、启用 Gitea 远程、落地 `.cursor/rules`。框架脚手架按搭框架目录可以做。
