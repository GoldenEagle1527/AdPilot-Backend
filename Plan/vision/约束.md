# 硬约束

状态：accepted  
新约束用 ADR。

| ID | 约束 |
| --- | --- |
| C-BE-1 | 后端必须是 Python + FastAPI。 |
| C-BE-2 | 模块化单体：一个 FastAPI 进程，一个业务一个包。 |
| C-BE-3 | PostgreSQL 18.x；SQLAlchemy 2 asyncio；asyncpg。禁止 psycopg（ADR 0014）。 |
| C-BE-4 | Redis 7.2.x，禁止 6.x 及 7.4/8.x。 |
| C-SEP-1 | 本仓只提供 API。禁止同源假设、禁止用 FastAPI 托管页面（ADR 0012/0019）。 |
| C-MOD-1 | 代码边界跟业务走：先业务块，再接口文件。 |
| C-PERM-1 | 授权在 `system-admin`。清单按 5.4.0 xlsx。禁止另造权限码。投放 CRUD 不预建。 |
| C-GIT-1 | Git。本仓已加 origin；合入 `feat/*` + PR → `main`。不建计划远程。 |
| C-PLAN-1 | 未开块的业务不开工。契约未写的 CRUD 不开工。 |
| C-SHARE-1 | `core` 只准 [`../architecture/共享白名单.md`](../architecture/共享白名单.md)。 |
| C-ASSET-1 | 不把截图当视觉规范。 |
| C-COMPLY-1 | [`../meta/公司研发规范.md`](../meta/公司研发规范.md)。 |
| C-DEP-1 | Docker + yaml；PG/Redis 不进应用镜像。开发 Compose，生产共用实例（ADR 0020）。 |
| C-AUTH-1 | Token 放 Header；密码登录；查库，Token 存 Redis（ADR 0016）。 |
| C-COMM-1 | 需求走群。接口变更：更新 OpenAPI 并发对接文本（ADR 0019）。 |
