# 硬约束

状态：accepted  
范围：不能违反。新约束用 ADR。

| ID | 约束 |
| --- | --- |
| C-BE-1 | 后端必须是 Python + FastAPI。 |
| C-BE-2 | 模块化单体：一个 FastAPI 进程，一个业务一个包。拆服务以后再说。 |
| C-BE-3 | 关系库 PostgreSQL 18.x；ORM SQLAlchemy 2 asyncio；驱动 asyncpg。禁止 psycopg（ADR 0014）。 |
| C-BE-4 | 缓存 Redis 7.2.x，禁止 6.x 及 7.4/8.x。 |
| C-FE-1 | 前端必须是 React（ADR 0015）。不得破坏业务切块，许可证须宽松。 |
| C-SEP-1 | 前后端完全分离：两套产物、**两台机器**、**两个应用 Git 仓**。接头是 HTTP + OpenAPI。禁止同源假设、禁止生产用 FastAPI 托管前端（ADR 0012/0018/0019）。 |
| C-MOD-1 | 代码边界跟业务走：先业务块，再前端/后端，再接口/页面。 |
| C-PERM-1 | 授权机制在 `system-admin`（ADR 0008/0010）。本阶段清单按 5.4.0 xlsx（ADR 0016）。禁止另造权限码。投放等页面不预建。 |
| C-GIT-1 | 版本走 Git。两个应用仓：后端 AdPilot、前端 AdPilot-Frontend。不建计划远程。现在不加 origin。 |
| C-PLAN-1 | 本阶段定义登录/用户/权限/角色并搭框架。契约未写的 CRUD 不开工。Cursor rules 仍不落地。 |
| C-SHARE-1 | `core` / 前端 `shared` / `shells` 只准 [`../architecture/共享白名单.md`](../architecture/共享白名单.md) 白名单。 |
| C-ASSET-1 | 不把截图当视觉规范。投放/素材/报表未到前不预建那些业务块。 |
| C-COMPLY-1 | 遵守 [`../meta/公司研发规范.md`](../meta/公司研发规范.md)：禁宝塔、许可证白名单、素材可商用。 |
| C-DEP-1 | 应用 Docker；配置 yaml 在 `deployment/`；PG/Redis 用共用实例，不进本项目镜像（ADR 0017）。 |
| C-AUTH-1 | Token 放 Header；密码登录；当前 mock（ADR 0016）。 |
| C-FE-2 | 前端禁止自有业务逻辑；业务请求必须打后端（ADR 0019）。 |
| C-COMM-1 | 需求走线下/群。接口变更：后端更新 OpenAPI 并发对接文本（ADR 0019）。 |
