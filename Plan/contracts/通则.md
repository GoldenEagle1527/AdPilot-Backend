# 契约

状态：accepted  
范围：同一业务里一人写接口、一人写页面时的唯一接头。

## 规则

1. **一个接口一份 markdown**，放在该业务的 `contracts/`。
2. **领该接口的人先写**。领页面的人只消费；有异议改这一份，不另起字段表。
3. 没有这份文件，不算可以两人同时干。
4. 最低字段见 [接口模板.md](接口模板.md)。缺字段表就不算可开工。
5. **当前正文就是最新表**。改接口必须升文档版本、写变更历史、更新 `contracts/最新表.md`。破坏性变更先快照到 `_history/`。细则：[architecture/契约版本.md](../architecture/契约版本.md)（ADR 0011）。
6. **给前端的真源是后端 OpenAPI**（ADR 0019）。本目录 markdown 只是现在写计划、给后端自己理接口用，不是前端必须 clone 的接头。接口变了按 [../backend/接口变更对接.md](../backend/接口变更对接.md) 发群。

## 路径约定（实现期）

建议 `/api/v1/<business-id>/...`。这是 **后端机上的路径**。前端完整 URL = 配置的 API 基址 + 该路径。未实现前只写在契约的「路径」字段里。路径版本只在破坏性变更时升到 `v2`；文档版本每次改字段都 +1。

两端部署在两台机器上，见 [architecture/前后端分机.md](../architecture/前后端分机.md)。
